# Posterior-mean bounded loadings

Posterior-mean bounded loadings

## Usage

``` r
# S3 method for class 'bayesqm_fit'
coef(object, ...)
```

## Arguments

- object:

  A `bayesqm_fit`.

- ...:

  Unused.

## Value

An `N x K` matrix of posterior-mean bounded loadings (the
correlation-scale loading of the accompanying paper).
